# PassVault

This is a secure desktop password manager built with Python and CustomTkinter. 
It allows users to generate strong passwords, stores credentials in an encrypted file and access the manager through a master password.
This project was built as a cybersecurity portfolio project to demonstrate 
secure password generation with encryption, GUI development, and file handling in Python

## Features

- Master password authentication
- Secure password generation
- Password strength analysis
- Password entropy calculation
- Estimated password crack time
- Username and password duplicate detection
- Search saved credentials
- Copy passwords to the clipboard
- Show/hide password
- CustomTkinter GUI

## Technologies Used

- Python
- CustomTkinter
- Cryptography using Fernet Encryption
- JSON
- PyCharm

## Files
- App.py: Start the application
- LoginPage.py: Master password login
- MainWindow.py: Main application window
- PasswordGenerator.py: Password generation
- PasswordChecker.py: Password strength and securoty checks
- Crypto.py: Handles the encryption and decryption
- Vault.py: Vault file handling

## Running the Project

Install the dependendencies for customtkinter, cryptography. Then run App.py
